# module_hdc1080 — датчик температуры и влажности HDC1080

> **Опциональный модуль.** Подключается через `src_filter` (define-флаг `MODULE_HDC1080`
> выводится из `src_filter` автоматически через `[registry]`).

Датчик HDC1080 (I2C): температура и относительная влажность. Публикует на ресурсную шину
`core_state` только доступность и значения; веб-страница и терминал — только просмотр.

- **Репозиторий:** https://github.com/Arcanum753/HDC1080
- **Папка:** `src/module_hdc1080/`
- **Флаг активации:** `MODULE_HDC1080` (генерируется в `src/modules_defines.h` из `src_filter`)
- **Registry:** `object=module_hdc1080`, `define=MODULE_HDC1080`, `namespace=hdc1080`,
  `web=1`, `loop=0`, `res=1`
- **Платформы:** ESP8266/ESP32 (тестирование — ESP32)
- **Зависит от ядра:** `core_web`, `core_state`, `core_task`, `core_terminal`

## Назначение

Чтение HDC1080 по I2C (`Wire`, фиксированный адрес `0x40`), проверка `MANUFACTURER_ID`
(`0xFE` == `0x5449`) и `DEVICE_ID` семейства `0x10xx` (`0x1000`, клон `0x1050`),
измерение T+RH 14 бит.

## Функциональные требования

- FR-HDC1080-1: Проверка manufacturer/device id перед использованием.
- FR-HDC1080-2: Конфигурация `0x02 = 0x0000` (14 бит, heater off).
- FR-HDC1080-3: Измерение: отдельные запросы T (`0x00`) и RH (`0x01`), пауза 20 мс, чтение 2 байт.
- FR-HDC1080-4: Публикация `hdc1080.available` (BOOL), `hdc1080.temperature` (F32, °C),
  `hdc1080.humidity` (F32, %RH).
- FR-HDC1080-5: Периодический опрос через `core_task.every("hdc1080_poll", …, 1000)`.
- FR-HDC1080-6: Веб-страница `hdc1080.html` — только показ значений.
- FR-HDC1080-7: Терминальная команда `hdc` — статус и значения.

## Аппаратные интерфейсы

| Интерфейс | Выводы по умолчанию | Примечание |
|-----------|---------------------|------------|
| I2C (HDC1080) | ESP32 21/22, ESP8266 4/5 (SDA/SCL) | общая шина `Wire`; адрес `0x40` |

## Веб-интерфейс

| Метод | URL | Назначение |
|---|---|---|
| GET | `/hdc1080/info` | CVT: состояние, адрес, ID, показания |
| GET | `/hdc1080/read` | CVT: только показания (опрос раз в 1 с) |
| GET | `/hdc1080/ver` | версия модуля |

Страница `hdc1080.html` (пункт меню — `web/_menu.html`). Полей редактирования нет.

## Ресурсы шины (namespace `hdc1080`)

| Ресурс | Тип | Описание |
|---|---|---|
| `hdc1080.available` | BOOL ro | датчик найден и измерение успешно |
| `hdc1080.temperature` | F32 ro | температура, °C |
| `hdc1080.humidity` | F32 ro | относительная влажность, %RH |

`<ns>.save` и `<ns>.mode` не регистрируются: у модуля нет сохраняемых настроек.

При потере датчика публикуется `available=false` и значения `0`; поиск повторяется на
каждом тике опроса (hot-plug). Модуль также служит источником компенсации для `module_ccs811`.

## Терминал

Компонент `module_hdc1080`, команда `hdc`, `editable = false`.

| Команда | Назначение |
|---|---|
| `hdc` / `hdc show` | состояние, адрес, ID, температура, влажность |
| `hdc help` | справка |

## Проверено (2026-11-19, ESP32)

- env `esp32-i2c-mapper`, прошивка `0.117.20261119_1754.2104`.
- Датчик: адрес `0x40`, manufacturer `0x5449`, device id `0x1050` (совместимый клон);
  показания `29.1 °C`, `73.0 %RH`.
- Раздельные чтения T/RH: последовательный режим клона отдавал влажность как `0xFFFF`.
- `/hdc1080.html` — 200; `/hdc1080/info|read|ver` — CVT; ресурсы есть в `/state/catalog`
  и `/macros/resources.json`.
- Терминал: `hdc`, `hdc show`, `hdc help`; обработка неизвестных подкоманд проверена.
- Модуль подтверждён как источник компенсации для `module_ccs811`.

## Ограничения

- T и RH измеряются отдельными запросами (по 20 мс), итого ≈40 мс раз в секунду
  (≈4 % времени main-loop). Это осознанный компромисс: последовательный режим на клонах
  с device id `0x1050` отдаёт влажность как `0xFFFF`.
- Поддерживаются device id семейства `0x10xx` (0x1000, 0x1050).
- Heater не используется; батарейное питание не контролируется.
- Модуль не сохраняет ничего на FS: конфига нет.

## Критерии приёмки

- `esp32-i2c-mapper` (или иной env с модулем) собирается.
- Страница `hdc1080.html` открывается, значения обновляются.
- `/state/catalog` содержит `hdc1080.available|temperature|humidity` с `rw=false`.
- Команда `hdc` печатает значения; при отключённом датчике — `not available`.
